TinyInstruments

Header only musical instruments for microcontrollers: realistic, sample based sound which fits into the flash memory of an ESP32, and a synthesized tonewheel organ.

  • Instruments (~700 KB each): upright piano, grand piano, electric piano (Wurlitzer), drum kit, tenor saxophone, clarinet, electric guitar with amplifier, electric bass, upright bass
  • Tonewheel organ (Hammond style) with rotary speaker (Leslie): synthesized, no sample data
  • Smaller versions with ~250 KB and ~150 KB, also as headers (versions and sizes)
  • Sample data compiled into flash, or loaded at runtime from any Stream (e.g. a file) into PSRAM
  • Output via arduino-audio-tools, input via arduino-midi (serial, BLE, TCP, UDP and USB midi as device or host)
  • 10 piano notes need about 29% of one core of an ESP32-S3
  • Examples from simple serial midi sketches up to a touch GUI with an on-screen piano keyboard (TinyMaterialDesign) and a player for General MIDI files (arduino-midi-fileparser)
  • All example sketches also build and run unchanged on the desktop (Arduino-Emulator)
  • Desktop player for a USB midi keyboard or midi files, which can also forward the midi to a microcontroller (serial, TCP, UDP, BLE)

Installation in Arduino

You can download the library as zip and call include Library -> zip library. Or you can git clone this project into the Arduino libraries folder e.g. with

cd ~/Documents/Arduino/libraries
git clone https://github.com/pschatzmann/TinyInstruments.git

The examples also need the following libraries, which are installed the same way:

git clone https://github.com/pschatzmann/arduino-audio-tools.git
git clone https://github.com/pschatzmann/arduino-midi.git

The midi-file-player example additionally needs:

git clone https://github.com/pschatzmann/arduino-midi-fileparser.git

The material-gui example additionally needs:

git clone https://github.com/pschatzmann/TinyMaterialDesign.git
git clone https://github.com/pschatzmann/TinyGPU.git
git clone https://github.com/pschatzmann/arduino-audio-driver.git

I recommend to use git because you can easily update to the latest version just by executing the git pull command in the project folder. To use the library on the desktop (tests, example sketches, desktop player), see Testing and Desktop Player.
