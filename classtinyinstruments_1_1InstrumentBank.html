Detailed Description

Maps midi program numbers (0..127, e.g. General MIDI) to instruments and optional channel effects. Assigned to a SampleSynthesizer, a program change message selects the instrument of the channel.

InstrumentBank bank;
bank.add(0, 7, piano); // General MIDI pianos
bank.add(29, 29, guitar, &crunch_amp); // overdriven guitar
synth.setInstrumentBank(&bank);
