Getting Started

Install arduino-audio-tools and arduino-midi. The material-gui example also needs TinyMaterialDesign, TinyGPU and arduino-audio-driver, the midi-file-player example arduino-midi-fileparser.

A sketch consists of:

  • a SampleSynthesizer which plays the notes
  • one or more Instruments: a sample set with the playing parameters, assigned to midi channels
  • SampleSynthesizerStream: provides the audio as arduino-audio-tools stream
  • SampleSynthesizerMidiAction: passes the midi events from arduino-midi to the synthesizer

The following sketch plays an instrument with a midi keyboard connected to a serial port and outputs the sound to an I2S DAC:

#include "AudioTools.h"
#include "Midi.h"
#include "TinyInstrumentsAudioTools.h"
#include "TinyInstrumentsMidi.h"
#include "samples/GrandPiano.h"
SampleSynthesizer synth;
Instrument piano = PianoInstrument(GrandPiano());
SampleSynthesizerStream in(synth);
I2SStream out;
StreamCopy copier(out, in);
SampleSynthesizerMidiAction action(synth);
MidiStreamIn midi_in(Serial2, action);
void setup() {
Serial2.begin(31250, SERIAL_8N1, 21, 22);
synth.setInstrument(-1, piano); // all midi channels
auto cfg = out.defaultConfig(TX_MODE);
cfg.copyFrom(in.defaultConfig()); // 44100 Hz, stereo, 16 bits
out.begin(cfg);
in.begin(cfg);
}
void loop() {
midi_in.loop();
copier.copy();
}

Other midi inputs of arduino-midi are used the same way, e.g. USB midi (MidiUsb.h, see piano-usb-midi):

#include "MidiUsb.h" // instead of Midi.h
...
MidiUsbDevice midi_in("TinyPiano", &action); // the board is a USB midi device
// MidiUsbHost midi_in(&action); // or: a USB midi keyboard on the board
void setup() {
midi_in.begin();
...
}

MidiUsbDevice needs a board with native USB: ESP32-S2/S3/P4 with Tools - USB Mode "USB-OTG (TinyUSB)", RP2040/RP2350 (#include <MIDIUSB.h> before MidiUsb.h with the default "Pico SDK" USB stack, or <Adafruit_TinyUSB.h> with "Adafruit TinyUSB"). MidiUsbHost needs the ESP32 Arduino core >= 3.3 (or Adafruit TinyUSB with host support) and an OTG adapter which supplies 5V to the keyboard; while the host is running the USB port can not be used for Serial. See the arduino-midi documentation for all platforms.

To use another instrument, include its header and use the matching preset:

Instrument Header Preset Midi channel
Upright piano samples/UprightPianoKW.h PianoInstrument(UprightPianoKW()) any
Grand piano samples/GrandPiano.h PianoInstrument(GrandPiano()) any
Drum kit samples/DrumKit.h DrumInstrument(DrumKit()) 10 (setInstrument(9, ...))
Tenor saxophone samples/TenorSax.h SaxophoneInstrument(TenorSax()) any
Electric guitar samples/ElectricGuitar.h GuitarInstrument(ElectricGuitar()) + GuitarAmp effect any
Clarinet samples/Clarinet.h ClarinetInstrument(Clarinet()) any
Electric bass samples/ElectricBass.h BassInstrument(ElectricBass()) + GuitarAmp(GuitarAmp::Bass) any
Electric piano samples/Wurlitzer.h ElectricPianoInstrument(Wurlitzer()) + optional TremoloEffect any
Upright bass samples/UprightBass.h UprightBassInstrument(UprightBass()) any
Tonewheel organ - (synthesized) OrganInstrument(organ) with TonewheelOrgan organ("888000000") + RotarySpeaker any

Each instrument also has a small version (~250 KB instead of ~700 KB), e.g. samples/GrandPianoSmall.h with PianoInstrument(GrandPianoSmall()), and (except the drum kit) an octave version (~150 KB), e.g. samples/GrandPianoOctave.h with PianoInstrument(GrandPianoOctave()). See Instruments for the details and Versions and sizes to compare them. Instead of compiling the samples into the program, they can also be loaded from a file.

Trying it out on the desktop

The instruments can be played on a computer with a USB midi keyboard or a midi file before you flash a board: see the Desktop Player.

All the examples below also build and run unchanged on the desktop (sound card, serial midi on stdin, USB midi from the keyboards connected to the computer (Linux), the GUI in a window): see running the examples on the desktop.
