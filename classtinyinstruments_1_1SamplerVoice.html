Plays a single note from a SampleZone: ADPCM decoding, pitch shifting with 4 point hermite interpolation, vibrato, decay envelope for the looped part, attack and release envelopes, velocity dependent lowpass and stereo panning. Detailed Description

Plays a single note from a SampleZone: ADPCM decoding, pitch shifting with 4 point hermite interpolation, vibrato, decay envelope for the looped part, attack and release envelopes, velocity dependent lowpass and stereo panning. Optionally the transposition is done with PSOLA, which does not change the length of the sound.
