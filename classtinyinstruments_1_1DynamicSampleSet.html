Detailed Description

A sample set which is loaded at runtime from a binary file (see tools/sfz2header.py –binary or tools/header2bin.py and the data folder).

The data is read from any object which provides size_t readBytes(char* data, size_t len), e.g. an Arduino Stream or File (SD, LittleFS, network client ...). The memory is allocated in PSRAM if available.

File file = LittleFS.open("/GrandPiano.bin");
DynamicSampleSet grand;
if (grand.begin(file)) piano = PianoInstrument(grand.sampleSet());
