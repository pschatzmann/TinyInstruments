Detailed Description

Integration with the arduino-audio-tools library: the SampleSynthesizer as AudioStream which can be copied to any audio output with a StreamCopy.

Integration with the arduino-midi library: a MidiAction which forwards the midi events to the SampleSynthesizer. It can be used with any midi input of arduino-midi (MidiStreamIn, MidiBleServer, AppleMidiServer ...).

enum class tinyinstruments::PitchShift : uint8_t
strong

How notes between the recorded notes are created.

Enumerator
Resample 

play the sample faster or slower: changes the length and the formants (best for pianos, guitars: crisp attacks)

Psola 

PSOLA: keeps the length and the formants (best for wind instruments and basses); needs pitch marks in the sample set, otherwise Resample is used
