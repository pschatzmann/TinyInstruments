Instruments

An Instrument combines a sample set (the recorded sounds) with the parameters which define how it is played. The included sample sets are CC0 (public domain), except the electric piano (CC-BY 3.0: attribution required), and need about 700 KB each (smaller versions: see Versions and sizes):

Versions and sizes

Each instrument is available in up to three versions:

  • full (~700 KB): all recordings and velocity layers, 32 kHz
  • small (~250 KB): one velocity layer, 22 kHz; soft notes are created from the loud recording with the velocity lowpass
  • octave (~150 KB): one recording per octave, one velocity layer, 22 kHz; the other notes are transposed (not for the drum kit)

All versions can be compiled into the program (header) or loaded from a file.

#include "samples/GrandPianoSmall.h"
Instrument piano = PianoInstrument(GrandPianoSmall());

Parameters

The presets return an Instrument which can be changed before it is assigned:

Instrument piano = PianoInstrument(GrandPiano());
piano.velocityCurve = 1.2f; // less dynamic
piano.stereoWidth = 0.0f; // mono
synth.setInstrument(-1, piano);

Pitch shifting

Only some notes are recorded (e.g. every whole tone): the notes in between are created from the closest recording. This can be configured per instrument:

Instrument sax = SaxophoneInstrument(TenorSax());
sax.pitchShift = PitchShift::Resample; // or PitchShift::Psola

The saxophone, clarinet and bass presets use Psola; their sample sets contain the pitch marks. Sample sets without pitch marks always use Resample, also if Psola is configured. Pitch bend and vibrato are always done by resampling (small changes).

Program changes

An InstrumentBank maps program numbers (e.g. General MIDI) to instruments and effects, so that a keyboard can switch the instruments:

InstrumentBank bank;
bank.add(0, 7, grand); // General MIDI pianos
bank.add(24, 31, guitar, &clean_amp); // guitars
bank.add(30, 30, guitar, &lead_amp); // distortion guitar: later entries take precedence
bank.add(32, 39, bass, &bass_amp);
bank.setDrumKit(drums); // program changes on channel 10 select the drums
synth.setInstrumentBank(&bank);

Program changes are queued like the other midi events. Unknown programs are ignored. If the new program uses another effect, the sounding notes of the channel fade out within 50 ms. The all-instruments example maps all instruments to the General MIDI programs.

GeneralMidiBank provides a ready-made General MIDI mapping of all instruments (e.g. for midi files): you pass the sample sets, it defines the instruments, the effects and the bank (see Playing MIDI Files):

GeneralMidiBank instruments; // global: it must stay alive
GeneralMidiBank::SampleSets sets;
sets.piano = &GrandPianoSmall();
sets.drums = &DrumKitSmall(); // missing sample sets are replaced or silent
instruments.begin(synth, sets);

Transposition

Each midi channel and each instrument can be transposed, e.g. when a part is played by an instrument with a lower range. The sounding note is the received key + the transposition of the channel + the transposition of the instrument:

synth.setTranspose(8, -24); // midi channel 9: two octaves lower
synth.setTranspose(-1, 12); // all channels: one octave higher
int semitones = synth.transpose(8);
Instrument whistle = clarinet; // the clarinet plays the whistle part ...
whistle.transpose = -24; // ... two octaves lower
bank.add(78, 78, whistle); // selected with the program change

The received keys are kept for the note off: a note which is held while the transposition changes keeps its pitch and is still released. The drum channel should not be transposed (the keys select the sounds). The midi-file-player example (GeneralMidiBank) uses transposed instruments for the piccolo and the whistle (see Playing MIDI Files).

Effects

An effect processes the audio of the midi channels it is assigned to, before it is mixed with the other channels. Channels which share the same effect object are processed together:

GuitarAmp amp(GuitarAmp::Lead);
synth.setEffect(0, &amp); // only midi channel 1

The control changes of the channel are passed to the effect. Own effects are derived from ChannelEffect (begin(), process(), controlChange(), hasTail()). Included: GuitarAmp.

Combining instruments

Each midi channel can have its own instrument. All channels share the voices of the synthesizer (TI_MAX_VOICES, default 10), so increase them before including the library if several instruments play together:

#define TI_MAX_VOICES 16
#include "TinyInstrumentsAudioTools.h"
...
synth.setInstrument(-1, piano); // all channels ...
synth.setInstrument(9, drums); // ... except channel 10
TinyInstrumentsAudioTools.h

Each full sample set needs about 700 KB, so two instruments need the "Huge APP" partition scheme on an ESP32 with 4 MB flash. Alternatives: use the small versions (~250 KB each), or load them into PSRAM.
