Detailed Description

Polyphonic, multi timbral sample player which is controlled with midi events. The midi methods (noteOn() etc) only queue the events, so they can be called from a different task than render(). The events are applied at the start of the next render() call.

Supported: note on/off, modulation wheel (CC1: vibrato), breath controller (CC2), volume (CC7), expression (CC11), sustain pedal (CC64), all sound off (CC120), reset all controllers (CC121), all notes off (CC123) and pitch bend (+/- 2 semitones by default). Received controllers can be mapped to other ones with mapController(), e.g. a knob which sends CC91 to the volume.

Polyphony: max maxNotes (default TI_MAX_VOICES = 10) notes sound at the same time, and max Instrument::maxNotes per channel. If another note is played, the quietest released note (or the oldest note) is faded out within a few milliseconds using one of the additional TI_FADE_VOICES voices. If you combine several instruments (e.g. piano and drums), increase TI_MAX_VOICES.

Maps a received midi controller to another one, e.g. mapController(91, 7): a knob which sends CC91 (reverb level in General MIDI) changes the volume of the channel (CC7).
