Drum Kit

samples/DrumKit.h contains an acoustic drum kit with percussion, mapped to the General MIDI percussion keys. It needs about 700 KB of flash.

Source: Virtuosity Drums by Versilian Studios (CC0, public domain), mid microphone, 2 velocity layers.

samples/DrumKitSmall.h (DrumKitSmall(), ~250 KB) has the same keys with one velocity layer at 22 kHz. There is no octave version: each key is a different sound, so the keys can't be created by transposing (see Versions and sizes).

#include "samples/DrumKit.h"
Instrument drums = DrumInstrument(DrumKit());
synth.setInstrument(9, drums); // midi channel 10

Keys without sample (e.g. timbales 65, 66) are silent.

Behavior

  • one shot: note off is ignored, every sound decays naturally
  • the closed (42) and pedal (44) hi-hat silence the open hi-hat (46)
  • no transposition: only the exact keys are played
  • max 8 drum notes at the same time (Instrument::maxNotes)

Piano and drums together

Both sample sets need 1.4 MB, so select the "Huge APP" partition scheme on an ESP32. The instruments share the voices of the synthesizer, so allow more notes at the same time before including the library:

#define TI_MAX_VOICES 16
#include "TinyInstrumentsAudioTools.h"
TinyInstrumentsAudioTools.h

See the piano-drums-serial-midi example.
